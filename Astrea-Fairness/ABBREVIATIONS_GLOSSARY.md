# Astrea-Fairness Project - Abbreviations & Terminology

| Abbreviation | Full Term |
|---|---|
| **AAC** | Augmentative and Alternative Communication |
| **DP_diff** | Demographic Parity Difference (selection rate difference between groups) |
| **DP_ratio** | Demographic Parity Ratio (80% Rule for legal compliance) |
| **EO_diff** | Equal Opportunity Difference (fairness for qualified candidates) |
| **FPR_diff** | False Positive Rate Difference (fair error distribution) |
| **PP_diff** | Predictive Parity Difference (prediction reliability across groups) |
| **TPR** | True Positive Rate (approval rate for qualified individuals) |
| **FPR** | False Positive Rate (false alarm rate / wrongful rejection) |
| **ROI** | Region of Interest (facial/image segment being analyzed) |
| **CNN** | Convolutional Neural Network (image analysis model) |
| **GDPR** | General Data Protection Regulation (privacy compliance) |
| **EEOC** | Equal Employment Opportunity Commission (US legal standard) |
| **CSV** | Comma-Separated Values (data file format) |
| **PDF** | Portable Document Format (report generation) |
| **HOG** | Histogram of Oriented Gradients (image feature extraction) |
| **RGB** | Red, Green, Blue (color space for image processing) |
| **z-score** | Normalized (z-score) standardization method for statistical analysis |
| **IoU** | Intersection over Union (image segmentation metric) |
| **LRW** | Lip Reading in the Wild (dataset) |
| **HMM** | Hidden Markov Model (sequential pattern analysis) |
| **DCT** | Discrete Cosine Transform (image compression technique) |
| **CTC** | Connectionist Temporal Classification (sequence modeling) |
| **BERT** | Bidirectional Encoder Representations from Transformers (NLP model) |
| **CER** | Character Error Rate (text bias measurement) |
| **HIPAA** | Health Insurance Portability and Accountability Act (healthcare compliance) |
| **ARM** | Advanced RISC Machine (processor architecture) |
| **GPIO** | General Purpose Input/Output (hardware interface) |
| **FP32** | 32-bit Floating Point (single precision) |
| **INT8** | 8-bit Integer (quantized precision) |
| **LIME** | Local Interpretable Model-agnostic Explanations (bias explainability) |
| **BiLSTM** | Bidirectional Long Short-Term Memory (sequence analysis) |
| **3D-CNN** | Three-Dimensional Convolutional Neural Network (video/spatial analysis) |
